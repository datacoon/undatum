# Community and discovery

undatum is a small project with real usage. This page tracks the remaining
community-surface work from the user-needs roadmap.

## GitHub Discussions

Q&A and ideas live in [GitHub Discussions](https://github.com/datenoio/undatum/discussions).
Issues stay for bugs and actionable features.

See also `CONTRIBUTING.md`.

## Dependency PRs

Dependabot is configured in `.github/dependabot.yml` for weekly pip security
patches (grouped) and monthly GitHub Actions updates. Historical Snyk bot PRs
were closed in favor of Dependabot.

## Downstream

[cratedb-toolkit](https://github.com/crate/cratedb-toolkit) is a known downstream
user of this ecosystem. Coordinate iterabledata/pyiterable migrations before
breaking import surfaces.
